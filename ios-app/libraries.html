iOS libraries worth knowing

18 libraries and tools, grouped by what they're for and ranked for Igor's setup: SwiftUI apps built by agents, log-first debugging, device deploys and one simulator at a time. Stars and last push are live from GitHub (2026-10-11). Savings are estimates against today's workflow, not measurements. Skips are dropped, and duplicates are cut to one per job: one SwiftUI skill (twostraws), one style guide (Airbnb, which matches swift-format), one general index (awesome-ios). Each section is sorted Adopt, then Consider; GitHub repos under 1,000 stars are left out (Apple's own docs have no stars and stay).

Igor's picks: adopt SwiftLint, swift-format, Maestro, swift-log, swift-collections, swift-algorithms, swift-async-algorithms, swift-argument-parser and Kingfisher. TCA: an optional spike to measure conversion cost against its value. Then (2026-10-11) also swift-dependencies, xcbeautify, fastlane (as a signing experiment), XcodeGen and SwiftUIX, with the rule no custom controls unless really required.

Second opinion: Codex (GPT-6 Astra)

  • Adds: xcbeautify (adopt as a CLI tool) and Pulse (only if HTTP debugging hurts); rows are marked Astra adds. Its top pick, swift-clocks (★343, a test clock for async code), falls under the 1,000-star cut, but it already comes in with swift-dependencies.
  • Demotes fastlane from top pick to a targeted signing experiment: first find out what actually broke a deploy.
  • Corrections, now applied: Maestro drives iOS simulators, not physical devices; Kingfisher handles local images too; SwiftLint's force-unwrap rule is opt-in; swift-log needs a backend; XcodeGen gives fewer conflicts, not none.
  • Savings: replace guesses with a one-week baseline (bug report to evidence, deploy cycles per fix, simulator minutes, signing failures by cause, Igor's minutes).
  • TCA spike: 4 hours plus 45 minutes of review, on one Context Grabber feature with async loading, debounce and cancellation, built both ways from the same baseline. Go only if it passes, stays in the timebox and the next change is cheaper; a tie keeps the current design.
